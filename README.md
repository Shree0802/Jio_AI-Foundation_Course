# Jio_AI_Course
AI Classroom Foundation Course by Jio Institute &amp; JioPC, designed to help students and beginners build practical AI skills. Learn how to use AI tools like ChatGPT, NotebookLM, and Adobe Express to enhance learning, creativity, productivity, and communication while understanding safe and effective AI usage.

## 📚 Course Modules

### Module 1: AI Basics & Prompt Engineering
Learn core AI concepts, understand LLMs and machine learning, and master effective prompting with AI tools like ChatGPT and Gemini.

### Module 2: AI for Learning & Creativity
Explore how AI can support research, self-learning, creative writing, idea generation, and problem-solving using tools like NotebookLM.

### Module 3: AI for Building & Communication
Learn to create engaging content, presentations, videos, voiceovers, music, and social media content using modern AI tools.
